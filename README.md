## Employee Shift Management System
This is a simple Java project I built for a university assignment to practice Object-Oriented Programming (OOP) and software design.

The application simulates a basic shift management system for a store, where managers can assign shifts to employees while making sure they don't exceed the legal working hours.

# Core Concepts Demonstrated
Object-Oriented Programming: I applied inheritance (Manager extends Employee), composition (a Store manages a list of Employees), and basic associations.

Business Logic Validation: Implemented a rule that automatically rejects a shift assignment if an employee exceeds the 40-hour legal limit per week.

Unit Testing: Wrote automated tests using JUnit to verify the 40-hour limit logic using multiple data sets (normal values, edge cases, and invalid inputs).

UML Modeling: Created Use Case, Class, Activity, and State diagrams to plan the system architecture before writing the actual code.

# Technologies Used
Java, JUnit, Eclipse IDE, Microsoft Visio (for UML documentation)

# A quick note on the code
Since this was a local university project, the class names, variables, and methods in the source code are written in Romanian. However, the system architecture and testing logic follow standard software engineering principles.
